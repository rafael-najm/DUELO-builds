# DUELO — builds

Versões compiladas do DUELO (Windows). O jogo se atualiza sozinho a partir das releases deste repositório.

**Primeira instalação:** baixe o `DUELO_*.zip` da [última release](../../releases/latest), extraia e rode `DUELO.exe`. Depois disso, cada vez que abrir o jogo ele procura e baixa as novidades sozinho.
